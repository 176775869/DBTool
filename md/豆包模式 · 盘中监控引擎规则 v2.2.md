## 豆包模式 · 盘中监控引擎规则 v2.2（标准版）

# 一、核心原则

- **实时驱动**：所有判定基于最新市场数据，非收盘数据。
- **状态继承**：从【昨日复盘报告】的全景表最后一行获取初始状态（状态标记、主线锚点、候选池、环境等级）。
- **信号触发**：当实时数据满足特定条件时，立即输出监控信号（买入/卖出/预警/状态变更）。
- **禁止主观**：不依赖任何外部知识或记忆，仅使用本规则和指定数据源。
- **竞价阶段**：9:15-9:25为竞价阶段，9:25-9:30竞价结束需按竞价后数据快速给出市场判断。
- **持仓状态**：关于持仓数据需要用户提供，如果用户没有提供需在复盘报告里获取，都没有则默认空仓。
- **执行清单唯一化**：盘中监控每次输出的买点信号，**最多只含1个标的**。若多个标的同时触发同类型买点，按规则手册12.3节优先级规则取最优。


# 二、数据源与更新频率

| 数据源 | 关键字段 | 更新频率 | 用途 |
|--------|----------|----------|------|
| 实时大盘指数 | 上证现价、涨跌幅、5日线、20日线、全市场成交额(预估) | 每分钟 | 环境等级动态判定 |
| 实时板块行情 | 板块涨幅、涨跌比、主力净流入 | 每分钟 | 主线评分动态更新 |
| 实时涨停数据 | 涨停个股、涨停时间、封单额、连板数、所属板块 | 实时 | 先锋识别、Ca/Cb判定 |
| 实时炸板数据 | 炸板个股、回封状态 | 实时 | 分歧强度判定 |
| 实时跌停数据 | 跌停个股、所属板块 | 实时 | 退潮预警 |
| 实时核心中军行情 | 中军现价、涨跌幅、成交额、5日线、10日线、20日线 | 实时 | 中军表现、破位判定 |
| 实时强势股数据 | 股票量比、趋势评分、现价 | 实时 | 趋势先锋识别 |
| 昨日复盘报告 | 全景表最后一行（状态、主线锚点、候选池、环境等级） | 每日开盘前 | 初始状态获取 |


# 三、环境等级动态判定（盘中）

## 3.1 初始等级
从【昨日复盘报告】继承环境等级。

## 3.2 盘中动态升级条件
当以下条件**同时满足**时，环境等级自动上调一级（S级不再上调）：
1. 半日成交额（截至11:30）≥ 昨日全日成交额 × 0.8
2. 上证指数 涨幅 > 1.5%
3. 或 上涨家数 > 4000家 且 涨停家数 > 80家

> **重要限制**：盘中动态升级仅适用于环境等级从C→B或B→A，**不改变C级核心定义（沪指<20日线）** 。即使触发动态升级条件，若沪指仍<20日线，总仓位上限仍为仓1，仅情绪判定可参考升级后的等级。

## 3.3 盘中动态降级条件
当以下条件**任一满足**时，环境等级自动下调一级（C级不再下调）：
1. 上证指数 跌破20日线（触发即降至C级）
2. 全市场成交额（预估）低于1万亿（A→B）或低于5000亿（B→C）
3. 上涨家数 < 500家

## 3.4 等级影响参数弹性调整

| 参数 | S级(放宽) | A级(标准) | B级(收紧) |
|------|----------|----------|----------|
| C启动涨停要求 | ≥5家 | ≥8家 | ≥10家 |
| D2竞价高开 | 2-7% | 3-7% | 4-7% |
| D2放量标准 | >20% | >30% | >40% |
| D3回踩均线 | 5或10日线 | 5日线 | 5日线且不破 |
| D3执行时间 | 盘中即可 | 尾盘(14:50后) | 必须尾盘 |
| 趋势Ca中军涨幅 | >2% | >3% | >4% |
| 趋势Ca涨停家数 | ≥3家 | ≥3家 | ≥5家 |


# 四、状态机监控（实时状态判定）

## 4.1 初始状态获取
从【昨日复盘报告】全景表最后一行获取：
- 状态标记（如 G5-1、H+6、Y+2）
- 主线锚点方向及阶段（如 算力/CPO G5-1，或无有效主线锚点）
- 候选池方向及阶段（如 机器人 D1-2）
- 环境等级

## 4.2 状态转移监控（实时触发）

### 4.2.0 状态切换时间窗口统一规则

监控引擎在检测到状态切换信号时，按以下规则执行：

| 切换类型 | 生效时间 | 监控引擎行为 |
|---------|---------|-------------|
| **H→G** | 次日确认后执行 | Ca日仅输出观察信号，不输出买点。次日Cb确认后才输出买点信号。 |
| **G→H** | **当日立即生效** | E信号触发后，立即输出清仓信号，状态标记当日切换。 |
| **H→Y** | **当日立即生效** | Y条件满足后，立即输出Y买点信号，状态标记当日切换。 |
| **Y→H** | **盘中立即生效** | 核心标的跌停/破5日线，立即输出卖出信号，状态标记盘中切换。 |
| **H内部子状态（F/P/B）** | 次日执行 | 以当日收盘数据为准，次日开盘执行对应操作。 |

### 4.2.1 Ca（启动日）监控

**触发条件（需同时满足）**：
1. 板块涨幅 > 2%（趋势型：中军涨幅 > 对应等级阈值）
2. 涨停家数 ≥ 对应等级阈值（S≥5，A≥8，B≥10）
3. 至少包含：2只一字板（或秒板） + 1只换手板
> 趋势型放宽：涨停≥对应等级阈值（S/A/B≥3）即可，不要求一字板

**监控输出**：
```
【Ca信号】方向：[板块名称] | 涨停家数：[X] | 一字板：[X] | 换手板：[X]
建议：预置锚点t，**仅观察**（清单内容：[板块名称]），**不执行买点**。等待Cb确认。
```

### 4.2.2 Cb（发酵确认）监控

**触发条件（需同时满足）**：
1. 当前状态为 Ca 或 Cb
2. 龙头封单较 Ca 日增加 ≥ 50%
3. 新增首板涨停 ≥ 2家

**监控输出**：
```
【Cb信号】方向：[板块名称] | 龙头封单增加：[X]% | 新增首板：[X]
建议：执行买点C-B，仓2-3，当天参与。
```

### 4.2.3 D1（首次分歧）监控

**触发条件（任一满足）**：
1. 盘中先锋炸板
2. 中军回踩5日线
3. 板块指数下跌

**强分歧附加判定**：同时满足 先锋断板 + 炸板率>40% + 中军破5日线 → 标记为强分歧

**监控输出**：
```
【D1预警】方向：[板块名称] | 强分歧：[是/否]
建议：
- D1-1：空仓等活口
- D1-2：尾盘D3低吸（仓2-3）
- D1-3：隔日竞价跟随（仓2-3）
- 强分歧：减仓预警
```

### 4.2.4 G2-1（主升确立）监控

**触发条件（需同时满足，隔日确认）**：
1. 昨日为 D1-3 或 D2-2
2. 今日跟风平均涨幅 ≥ 2%
3. 中军站稳5日线
4. 扩散系数 ≥ 0.8

**监控输出**：
```
【G2-1信号】方向：[板块名称] | 主升确立
建议：持有不加仓。此为**主升确立点**。
```

### 4.2.5 E（退潮确认）监控

**触发条件**：
常规：三者其二立即触发
1. 中军跌破20日线
2. 板块内跌停 ≥ 3只
3. 板块评分 < 3.0 连续2日

**快速通道**：跌停 > 50家 + 主线中军跌停 + 指数跌 > 5%

**监控输出**：
```
【E信号】方向：[板块名称] | 退潮确认
建议：清仓该板块所有持仓。
```

### 4.2.6 P（炮灰）监控

**触发条件**：

**P-方向（方向级炮灰）**：
1. 当前状态为 H（混沌期）
2. Ca→Cb后连续2个交易日跟风均涨幅<2%+扩散系数<0.8+中军未站回5日线
3. 或 G1后A杀（G1≤1日+板块批量跌停≥3只）

**P-个股（个股级炮灰）**：
1. 当前状态为 H（混沌期）
2. 个股连板≥2板或当日先锋板，且换手率>5%（非一字）
3. 有板块联动（至少2只跟风）
4. 当日跌停或-7%以上大阴线确认失败

**监控输出**：
```
【P-方向信号】方向：[板块名称] | 修复失败
建议：清仓该方向所有持仓，退回H。

【P-个股信号】标的：[个股名称] | 高辨识度诱多失败
建议：将该股列入黑名单，不抄底、不博反弹。铁律V适用。
```

### 4.2.7 H（混沌期）监控

**盘中必做四项主动扫描**：
1. **B冰点套利条件检查**：上涨家数<1500是否已连续2日？前主线核心中军是否缩量企稳（连续2日跌幅<3%且成交缩量≥40%）？
2. **Y妖股条件扫描**：是否存在连板≥4板或5日涨幅≥15%且连续3日换手>5%的独立标的？（观察扫描，非确认执行）
3. **指数企稳信号监测**：沪指是否出现连续收阳/长下影线？
4. **P-个股候选扫描**：H混沌期内，是否出现连板≥2板且换手>5%且有板块联动的标的？若有，标记为“P-个股候选”，**只观察，不参与，等它死亡确认**。

**监控输出**：
```
【H混沌期扫描】冰点套利条件：[满足/不满足] | Y妖股接近：[是/否] | 指数企稳尝试：[是/否] | P-个股候选：[有/无]
建议：空仓等待。若出现指数企稳日+共振Ca方向→设预置锚点t；若连续5交易日无有效Ca且未进入Y→可启用B冰点套利；若满足Y条件→转入Y。
```


# 五、买卖点监控信号

## 5.1 买点信号

### 5.1.1 C-A启动

**触发条件**：
1. 检测到 Ca 信号
2. 板块内存在符合唯一最优标的

**输出**：
```
【买点C-A】方向：[板块名称] | 标的：[唯一最优标的] | 仓位：仓3-4 | 时间窗口：当天参与，隔日不强则减
```

### 5.1.2 C-B确认

**触发条件**：检测到 Cb 信号

**输出**：
```
【买点C-B】方向：[板块名称] | 标的：[龙头名称] | 仓位：仓2 | 时间窗口：当天参与
```

### 5.1.3 D1开板回封

**触发条件**：
1. 当前状态为 D1
2. 龙头开板后午盘前回封
3. 封单/成交 > 1.5

**输出**：
```
【买点D1开板回封】方向：[板块名称] | 标的：[龙头名称] | 仓位：仓4 | 时间窗口：当天打板，不回封放弃
```

### 5.1.4 D2活口弱转强

**触发条件**：
1. 当前状态为 D1-3 或 D2-2
2. 竞价高开在对应等级阈值内
3. 竞价放量 > 对应等级阈值
4. 开盘15分钟内拉升

**输出**：
```
【买点D2弱转强】方向：[板块名称] | 标的：[活口名称] | 仓位：仓2-3 | 时间窗口：次日早盘确认
```

### 5.1.5 D3中军低吸

**触发条件**：
1. 当前状态为 D1-2 或 D2-2
2. 中军回踩对应等级均线
3. 缩量企稳（成交量较前日萎缩）
4. 次日不创新低

**输出**：
```
【买点D3低吸】方向：[板块名称] | 标的：[中军名称] | 仓位：仓2-3 | 时间窗口：按等级执行
```

### 5.1.6 B冰点套利

**触发条件**：
1. 当前状态为 H（混沌期）
2. 连跌（上涨家数 < 1500）≥ 2天
3. 前主线核心中军止跌缩量企稳（连续2日跌幅<3%+成交缩量≥40%）

**输出**：
```
【买点B冰点】方向：[前主线名称] | 标的：[核心中军] | 仓位：仓1-2 | 时间窗口：尾盘低吸，隔日套利，失败退回H
```

### 5.1.7 Y妖股出击

**触发条件**（需同时满足）：
1. 当前状态为 Y（妖股模式确认，单日触发即生效）
2. 沪指<20日线（环境等级C级）
3. 存在独立抱团标的（满足任一风格）：
   - 连板风格：连板≥4板，且所属板块评分<3.5（非主线）
   - 趋势风格：5日累计涨幅≥15%，且连续3日换手率>5%（剔除一字板锁仓股），且所属板块评分<3.5（非主线）
4. 无任一板块主线评分≥4.0（确认当前市场无主升主线）

> **旗帜与枪的区分**：
> - **观赏型妖股（旗帜）** ：一字板独食，换手<5%，无参与机会 → 确认Y状态存在，但**不输出买点**
> - **操作型妖股（枪）** ：换手充分（连续3日换手>5%），有回踩买点 → **唯一可输出买点的Y标的**

**完整判断流程**：
- 第一步：引擎检查当前状态是否为 Y（继承自复盘或触发后更新）
- 第二步：若是，则检查上述条件②③④
- 第三步：①②③④全部满足 → 进一步区分“旗帜”和“枪” → 只有“枪”才输出买点信号

**输出**：
```
【买点Y妖股】标的：[操作型妖股] | 仓位：仓1（10%） | 时间窗口：尾盘低吸（14:50后）或回踩5日线
止损：连板断板即走；趋势股破5日线即走。触发后进入3日缓冲期，最长持有5个交易日，5日内未创新高强制清仓。
```

# 六、主线评分动态监控

## 6.1 评分规则

| 指标/权重 | 5分 | 3分 | 1分 |
|-----------|-----|-----|-----|
| 政策强度(20%) | 国家级重磅 | 地方政策 | 无 |
| 资金流入(30%) | 板块涨幅>5% | >2% | <2% |
| 涨停数量(20%) | ≥15家 | ≥10家 | <5家 |
| 先锋封单(15%) | >5亿 | >2亿 | ≤2亿 |
| 中军表现(15%) | 核心中军涨停 | 核心中军涨>5% | 核心中军平或跌 |

## 6.2 评分更新频率
- 实时更新：资金流入、涨停数量、先锋封单、中军表现 **每5分钟** 重新计算
- 固定值：政策强度当日不变

## 6.3 评分阈值监控
- ≥4.5：核心主线 → `【主线评分-核心】`
- 4.0~4.4：次级主线 → `【主线评分-次级】`
- 3.0~3.9：轮动方向 → `【主线评分-轮动】`
- <3.0：放弃方向 → `【主线评分-放弃】`


# 七、角色识别监控

## 7.1 识别标准

| 角色 | 识别规则 |
|------|----------|
| 连板先锋 | 属该方向，连板数最高，封板时间早，封单强；优先10cm主板。*Ca日窗口放宽至前1交易日。* |
| 趋势先锋 | 属该方向，量比≥1.5，趋势评分最高，≤2板；优先100元以内。*Ca日按12.5.2锚定规则。* |
| 核心中军 | 属该方向，成交额最大且市值居前（板块内前3）。*Ca日按12.5.3锚定规则。* |
| **活口** | 属该方向，分歧日跌幅<3%，分时在均线上方，且**未破5日线**。活口是“板块分歧中的幸存者”，是弱转强修复时最可能成为新龙头的标的。**D1日确认活口 → 次日D2弱转强买点的前置条件**。 |
| 卡位 | 龙头断板当日逆势涨停 → 不参与 |

## 7.2 风格判定

- **连板主导**：优先 连板先锋 > 核心中军 > 趋势先锋
