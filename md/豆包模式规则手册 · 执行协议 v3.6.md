## 系统内核与铁律

### 确定性原则

豆包模式是一套**确定性状态机**。只要输入数据完整、客观，每日的正确操作（状态、主线、角色、买点/卖点）在理论上是**唯一且可预先计算**的。实践中因"隔日确认"规则（铁律III）导致的延迟，不影响其最终唯一性。交易者应摒弃主观预判，完全依赖规则输出。


### 九条铁律（三态铁律版）

> **设计理念**：市场90%的时间不在主升期。九条铁律从三个层级（状态识别层→操作执行层→通用执行层）分别约束G/H/Y三态下的操作行为。


#### 🔴 三条核心铁律（状态识别层）

| 编号 | 铁律 | 内容 |
|:---:|------|------|
| **I** | **先判态，后操盘** | 每日开盘前，必须确认当前市场状态是 **G主升 / H混沌 / Y妖股** 三者之一。**状态未明确前，不进行任何交易决策**。状态由状态机唯一判定，禁止主观"我觉得快主升了"而提前进场。 |
| **II** | **状态锁定，操作跟随** | 状态一旦确认，当日所有操作必须严格遵循该状态下的操作清单。**禁止在H状态做G的买点，禁止在Y状态做H的轮动，禁止在G状态做Y的抱团**。状态切换由状态机触发，交易者不预测、不抢跑。 |
| **III** | **状态切换，隔日确认（Y例外）** | 除Y模式外，所有状态切换以收盘数据为准，次日执行。Y模式触发和退出均为铁律III的唯一例外——满足条件即当日生效，无需隔日确认。禁止盘中"感觉要切换了"而提前调仓。 |


#### 🟠 三条执行铁律（操作执行层）

| 编号 | 铁律 | 适用状态 | 内容 |
|:---:|------|---------|------|
| **IV** | **主升只做主线，分歧只做活口** | **G状态** | 主升期内，**只做主线锚点方向**，放弃所有支线轮动。分歧日（D1/D2）只做活口分离确认，不做反包、不做首阴、不抄底跟风。**仓位上限由环境等级决定（仓1-4）** 。 |
| **V** | **混沌不猜底，炮灰不重仓** | **H状态** | 混沌期内：① **不抄底**（F修复不参与，除非通过B冰点套利）；② **不追新方向的首日启动**（Ca日不执行买点，预置锚点只观察）；③ **P-方向/P-个股确认后坚决清仓/拉黑**，不抱幻想；④唯一例外是**B冰点套利**（仓1，隔日），但需严格满足条件。**总仓位上限仓1（10%）** ，或空仓。【修订】**P-方向的独立高标豁免规则见状态速查表P栏，不适用本条"拉黑"指令。** |
| **VI** | **妖股只低吸，破线即离场** | **Y状态** | 妖股模式下：① **只做独立抱团标的的低吸**（尾盘14:50后或回踩5日线），不追高、不打板；② **仓位严格仓1（10%）** ，单票不超过总仓位的50%；③ **破5日线即走、断板即走、5日不创新高即走**；④不因"妖股涨了后悔没重仓"而加仓，不因"妖股跌了想补仓"而摊平。 |


#### 🔵 三条辅助铁律（通用执行层）

| 编号 | 铁律 | 内容 |
|:---:|------|------|
| **VII** | **固定锚，定操作** | 每日操作由当前市场状态 + 锚点阶段唯一决定。状态 = f(环境等级, 锚点T/预置锚点t/H0/Y0, 主线评分)。输入当日客观数据，输出唯一的状态和操作清单。**禁止在状态未明确时"抢跑"或"猜顶底"**。 |
| **VIII** | **止损不是破线等，弱信号来提前走** | 不等破位确认才止损。看到弱信号（量价背离、跟风走弱、封单骤减），**提前减仓或离场**。Y模式破5日线即走，连板断板即走，不等次日反包。 |
| **IX** | **每日执行清单，只列当日可执行操作** | 每日盘前/盘中输出执行清单，**只列当日可执行的买点/卖点/持仓处理**。观察标的单独标注"仅观察"，不列入执行清单。**清单为空时，当日唯一操作是"空仓等待"** 。 |


#### 三态速查卡（快速索引）

| 状态 | 一句话定义 | 核心操作 | 仓位上限 | 绝对禁止 |
|------|----------|---------|---------|---------|
| **G主升** | 有主线，有锚点，主升周期运行中 | 只做主线核心，分歧买活口，一致持仓 | 仓1-4（由环境等级决定） | 做支线、做轮动、做反包 |
| **H混沌** | 无主线，无锚点，P炮灰频出，F反复修复失败 | **空仓等待**，唯一例外是B冰点套利（仓1） | 仓1（10%）或0 | 抄底F、追Ca、重仓P |
| **Y妖股** | C级环境，无主线，独立抱团高辨识度标的 | 尾盘低吸独立妖股（仓1），破线即走 | 仓1（10%） | 追高、加仓、补仓、打板 |

## 一、状态机（唯一判定依据）

**市场三种状态**：

```
主升周期：Ca → Cb → G1 → D1 → G2 →..D(N-1) → G(N)..D(N) → F → E
混沌期（H）：E后无主线，等新方向走出来（可包含反复F修复、P转G2不及预期、B超跌套利）
妖股模式（Y）：E后市场主跌，独立抱团（连板>=4或趋势股逆势抱团）
```


### H混沌期内部循环图

> H混沌期不是消极等待，而是积极观察。F/P/B是H内部的三种"扰动"，它们不改变H的主状态，但影响H内部的节奏判断。

```
                    ┌─────────────────────────────────────┐
                    │           H 混 沌 期               │
                    │    (无主线，无锚点，等待状态)        │
                    └───────────────┬─────────────────────┘
                                    │
              ┌─────────────────────┼─────────────────────┐
              ↓                     ↓                     ↓
      ┌───────────────┐   ┌───────────────┐   ┌───────────────┐
      │  F 修复尝试   │   │  P 炮灰确认   │   │  B 冰点套利   │
      │ (E后或D后)   │   │ (方向/个股)   │   │ (仓1，隔日)   │
      └───────┬───────┘   └───────┬───────┘   └───────┬───────┘
              │                   │                   │
              ↓                   ↓                   ↓
      超预期→G(N+1)     【新增】独立高标豁免→Y   隔日了结→退回H
      失败→退回H       否则退回H(继续等待)
```

### 状态切换时间窗口统一规则

| 切换类型 | 生效时间 | 说明 |
|---------|---------|------|
| **H→G** | 次日确认后执行 | 需指数企稳日+共振Ca方向，Ca日设预置锚点t，次日Cb确认后方可执行买点。不抢跑。 |
| **G→H** | **当日立即生效** | E确认当日立即退出，无需隔日确认。退潮信号满足即清仓。 |
| **H→Y** | **当日立即生效** | 铁律III唯一例外。单日满足条件即触发，无需隔日确认。【新增】P-方向独立高标豁免触发的H→Y同样适用当日生效。 |
| **Y→H** | **盘中立即生效** | 核心标的跌停/破5日线，盘中立即退出，不等收盘。 |
| **H内部子状态（F/P/B）** | 次日执行 | 以当日收盘数据为准，次日执行对应操作。 |


### 状态速查表

| 状态 | 名称 | 定义 | 量化触发条件 | 操作指令 |
|------|------|------|-------------|---------|
| **Ca或者A** | 启动日 | 板块首次批量涨停 | ≥2只一字板(秒板)+≥1换手板+板块>2%；趋势型：中军放量>5%+板块成交创20日新高+板块>2% | 预置锚点，**仅观察**。清单内容：[预置锚点t方向名称]，**不执行买点**。 |
| **Cb** | 发酵确认 | Ca次日确认发酵延续 | 龙头封单较Ca增≥50%，且新增≥2首板 | 可加仓至仓2-3，执行买点C |
| **G1-n** | 首次主升 | 板块首次持续上涨 | 中军沿5日线上行或滞涨；n每日递增，跳过非交易日 | 持有不加仓 |
| **D1-n** | 首次分歧 | 主升后首次回调考验 | 盘中先锋炸板/中军回踩，次日确认；强分歧：先锋断板+炸板率>40%+中军破5 | D1-1：空仓等活口；D1-2：尾盘D3低吸(仓2-3)；D1-3：隔日竞价跟随(仓2-3)；D1+：减仓预警 |
| **G2-1** | **主升正式确立** | D1后弱转强修复成功，次日确认 | 跟风平均涨幅≥2%、中军站稳5日线、扩散系数≥0.8 | 持有不加仓。此为**主升确立点** |
| **G(N)-n** | 主升 | 确立主升后持续上涨 | 中军沿5日线上行或滞涨不创新高；n每日递增,G-D循环N次 | 持有不加仓 |
| **D(N)-n** | N次G后的分歧调整 | 确立主升后第N次 | 中军回踩关键均线，活口分离确认；n每日递增 | 活口分离确认买入，中军企稳回踩关键均线低吸 |
| **F** | **破位反弹（B浪修复）** | 主升后前一日出现破位信号，修复尝试 | 前一日已出现破位信号（中军破20日线 或 板块批量跌停≥3只）。今日出现修复尝试（跟风平均涨幅>0，但未站回关键均线） | 轻仓持龙头观察。修复超预期→G（N+1），切换下一阶段主升；分离信号触发→确认E退潮 |
| **P** | **炮灰（主升失败）** | **主升确立前**（H混沌期），新方向未能有效进入主升或主升后立即失败 | **P分为两个子类型：** <br>• **P-方向**：Ca→Cb后，连续2个交易日跟风均涨幅<2%且扩散系数<0.8且中军未站回5日线；或G1后A杀；<br>• **P-个股**：H混沌期内，连板≥2板且换手>5%的个股，次日跌停或-7%以上大阴线确认失败 | **P-方向**：清仓该方向所有持仓，退回H；【修订】**若该方向最高连板龙头满足下方"豁免规则"，则该龙头豁免清仓指令，移入Y模式操作池。** <br>**P-个股**：将该股列入黑名单，不抄底、不博反弹。铁律V适用。 |
| **E** | 退潮确认 | 主线正式结束 | 中军破20日线+批量跌停≥3只+评分<3.0连续2日；快速通道：跌停>50家+主线中军跌停+指数跌>5%三者其二立即E | **清仓该板块所有持仓** |
| **H** | **混沌期** | E确认后，市场无主升主线，且未进入主跌（指数可能横盘、弱跌或反复出现F修复失败）。涵盖情形：①有方向尝试但走不出主升（Ca→P）；②无方向尝试，指数横盘震荡；③反复出现F→G失败。 | E已触发；不满足Y模式条件；无任一板块主线评分≥3.5且连续2日；沪指未出现连续3日跌幅>1.5%的主跌形态（主跌则转Y） | **空仓等待**（B冰点套利除外）。若出现指数企稳日+共振Ca方向→设预置锚点t；若连续5交易日无有效Ca且未进入Y→可启用B冰点套利；若满足Y条件→转入Y |
| **B** | 冰点套利 | 混沌冰点后的短暂修复 | 连跌(上涨家数<1500)≥2天+**前主线核心中军止跌缩量企稳**（连续2日跌幅<3%且成交额较峰值缩量≥40%） | 尾盘低吸(仓1)，隔日套利，失败退回H。*优先选择前主线（E退潮方向）的核心中军*。**本质是"捡尸体"——做前主线核心中军的超跌反抽，隔日了结，不做主升预期。持有周期不超过2个交易日。** |
| **Y** | 妖股模式 | C级环境+独立抱团（连板或趋势股） | **单日满足以下全部条件即触发，当日生效，进入3日缓冲期**：①沪指<20日线（环境等级C级）；②存在**独立抱团标的**（满足任一风格）：<br>— 连板风格：连板≥4板，且所属板块评分<3.5（非主线）；<br>— 趋势风格：5日累计涨幅≥15%，且连续3日换手率>5%（剔除一字板锁仓股），且所属板块评分<3.5（非主线）；<br>③无任一板块主线评分≥4.0（确认当前市场无主升主线） | 选独立抱团标的，**仓1（10%）** ，单票≤50%。买点：尾盘低吸（14:50后）或回踩5日线。止损：连板断板即走；趋势股破5日线即走。**缓冲期3日**：缓冲期内只要核心标的未破5日线且未跌停，Y状态延续。**最长持有周期5个交易日**，若5日内未创新高则强制清仓。 |

**【新增】P-方向内独立高标的豁免规则（炮灰堆中夺旗）：**

> 当某一方向被标记为 **P-方向** 时（跟风全灭、中军破位、扩散系数失效），若该方向内的**最高连板龙头**在P-方向确认当日（即触发标记的T日）或次日（T+1日），**逆势晋级至4连板及以上**，且满足以下**全部**豁免条件：
> 1. **换手充分**：最近3个交易日中至少有2日换手率 > 8%（排除一字板独食）；
> 2. **板块背离确认**：该股当日涨幅与所属板块指数涨幅之差 > 5%（确认独立抱团，而非板块共振）；
> 3. **未触发跌停**：P-方向确认当日及次日，该个股未出现跌停（-10%/-20%）；
>
> 则该个股**自动豁免于P-方向的"清仓/拉黑"指令**，视为触发 **H→Y（妖股模式）** 的独立抱团信号。操作上：
> - **当日立即生效**（参照铁律III的Y例外规则），将该个股移入Y模式操作池；
> - 执行铁律VI（仓1、尾盘低吸/回踩5日线、破线即走）；
> - **该方向其余跟风个股仍按P-方向处理**（清仓拉黑），不可混为一谈。
>
> **防火墙条款**：若该龙头在P-方向确认前，已**连续3个交易日为一字板或T字板（即无有效换手）** ，则该龙头**不适用豁免规则**，视为"观赏型旗帜"而非"操作型枪"，执行清仓拉黑。
>
> **反向约束**：若该龙头在P-方向确认后2个交易日内未能继续晋级（即断板），或出现跌停，则立即回归P-个股定义，恢复"拉黑"指令，Y模式同步退出。

| **E** | 退潮确认 | 主线正式结束 | 中军破20日线+批量跌停≥3只+评分<3.0连续2日；快速通道：跌停>50家+主线中军跌停+指数跌>5%三者其二立即E | **清仓该板块所有持仓** |
| **H** | **混沌期** | E确认后，市场无主升主线，且未进入主跌（指数可能横盘、弱跌或反复出现F修复失败）。涵盖情形：①有方向尝试但走不出主升（Ca→P）；②无方向尝试，指数横盘震荡；③反复出现F→G失败。 | E已触发；不满足Y模式条件；无任一板块主线评分≥3.5且连续2日；沪指未出现连续3日跌幅>1.5%的主跌形态（主跌则转Y） | **空仓等待**（B冰点套利除外）。若出现指数企稳日+共振Ca方向→设预置锚点t；若连续5交易日无有效Ca且未进入Y→可启用B冰点套利；若满足Y条件→转入Y |
| **B** | 冰点套利 | 混沌冰点后的短暂修复 | 连跌(上涨家数<1500)≥2天+**前主线核心中军止跌缩量企稳**（连续2日跌幅<3%且成交额较峰值缩量≥40%） | 尾盘低吸(仓1)，隔日套利，失败退回H。*优先选择前主线（E退潮方向）的核心中军*。**本质是"捡尸体"——做前主线核心中军的超跌反抽，隔日了结，不做主升预期。持有周期不超过2个交易日。** |
| **Y** | 妖股模式 | C级环境+独立抱团（连板或趋势股） | **单日满足以下全部条件即触发，当日生效，进入3日缓冲期**：①沪指<20日线（环境等级C级）；②存在**独立抱团标的**（满足任一风格）：<br>— 连板风格：连板≥4板，且所属板块评分<3.5（非主线）；<br>— 趋势风格：5日累计涨幅≥15%，且连续3日换手率>5%（剔除一字板锁仓股），且所属板块评分<3.5（非主线）；<br>③无任一板块主线评分≥4.0（确认当前市场无主升主线）<br><br>**【新增】触发来源扩展**：除上述"自然触发"外，P-方向确认后满足豁免规则的独立高标，同样触发Y模式，执行相同规则。 | 选独立抱团标的，**仓1（10%）** ，单票≤50%。买点：尾盘低吸（14:50后）或回踩5日线。止损：连板断板即走；趋势股破5日线即走。**缓冲期3日**：缓冲期内只要核心标的未破5日线且未跌停，Y状态延续。**最长持有周期5个交易日**，若5日内未创新高则强制清仓。 |

> **Y模式"旗帜"与"枪"的区分**：
> - **观赏型妖股（旗帜）** ：一字板独食，无换手，无参与机会。作用是**确认Y状态存在**，但不可操作。
> - **操作型妖股（枪）** ：有换手（连续3日换手>5%），有回踩，有买点。是Y模式下真正可操作的标的。
> 
> Y模式触发后，核心任务是从"旗帜"的示范效应中，找到"枪"——即有换手、可参与的趋势型妖股。【新增】**P-方向豁免规则中，换手>8%的硬门槛已确保豁免标的天然属于"枪"而非"旗帜"。**


### 转移规则

- 主路径：Ca→Cb→G1→D1→G2→..D(N-1)→G(N)..D(N) → F → E, D和G后面的数字N代表一致(上涨)分歧(调整)次数,一定是**第N次的G在前D在后**.
- Ca可直接进G1（V型反转）,也可以日内启动到高潮隔日进入D1。状态可以跳过但必须符合客观节奏规律。
- 强制继承：按历史快照n(该状态持续交易日数，必须跳过非交易日)值递推，状态不变则n+1，状态变则重置为1
- 强势主升：D和G后面的数字N递推循环构成主升浪，强势主线可达5(N)浪即G1-D1-G2-D2-G3-D3...一直循环
- 锚点切换：须三日缓冲（挑战者连续3日评分≥旧锚点+中军连续3日站上5日线+旧锚点中军连续3日跌破10日线）；若未满足但候选处G2阶段可双锚点并行最长5天
- E后分支：有新方向尝试或指数横盘震荡→H；无方向尝试+主跌→Y。**补充**：若C级环境下出现**高辨识度独立标的**（连板≥4板或5日累计涨幅≥15%且连续3日换手>5%，且所属板块评分<3.5），即使市场未进入主跌，也可当日转入Y模式。Y模式优先级高于H，检测到符合条件的独立标的后，立即退出H进入Y。若后续独立标的破5日线或跌停，则立即退回H。此规则与上述"无方向尝试+主跌→Y"为并列关系，满足任一即触发Y。

**【新增】转移路径：P-方向失败 → 独立高标活口 → Y模式（炮灰堆中夺旗）**

> 当H混沌期内某一新方向尝试失败，被标记为`P-方向`时，若该方向内最高连板龙头在确认失败当日或次日，逆势独立走强（标准见状态速查表P栏豁免规则），则该方向**不退回普通H状态**，而是直接触发`H→Y`状态切换（当日生效）。
>
> 此路径与现有`H→Y`（无方向尝试+主跌/或独立抱团）为**并行补充关系**，专门处理"方向失败但个股胜出"的混沌期特殊场景。切换生效后，**3日缓冲锁定窗口**自Y触发日起算，规则同速查表Y栏。

- H中D1修复失败→P→退回H
- **H中Ca→Cb后强度不足的快速淘汰**：若新方向在完成Ca和Cb后，连续2个交易日（即Ca后第3-4日）跟风平均涨幅均<2%且中军未站回5日线，则直接标记P-方向退回H。【修订】P-方向确认同时，检查该方向最高连板龙头是否满足豁免规则（见速查表P栏），若满足则转入Y模式。
- **H中G1后立即A杀的快速淘汰**：若新方向进入G1后，G1仅持续≤1个交易日，次日即出现批量跌停≥3只或中军破5日线且无弱转强修复，则直接标记P-方向退回H。【修订】P-方向确认同时，检查该方向最高连板龙头是否满足豁免规则（见速查表P栏），若满足则转入Y模式。
- **混沌期内新Ca的V型反转确认条件**：Ca日后连续2个交易日（跳过非交易日）板块延续上涨，且中军（取成交额最大且市值居前）累计涨幅≥5%，且两个交易日内均无批量跌停（<3只跌停）。满足则直接进入G1，新周期开启，无需等待D1→G2。
- 全景表状态栏锚定在**最先启动、贯穿最久的主线锚点**的周期标记上。锚点对应状态就是市场状态，**市场状态唯一**，优先级锚点（T、H、Y）> 预置锚点 > 候选池支线。
- **主线分歧破位不要立即切换E，需要等F-E确认, F修复超预期进入下一个G（N+1）主路径**
- H与Y的状态确认时间：
1. **混沌期H**：E确认后的第一个交易日自动进入H，无需额外时间确认。H持续期间，每日检查是否出现新Ca方向（Ca定义见速查表）。若连续5个交易日无Ca且未进入Y，可启用B冰点套利，但主线锚点仍为空。
2. **妖股模式Y**：**单日满足条件即触发，当日生效，无需2日确认**（见速查表）。触发后自动进入**3日缓冲锁定窗口**，缓冲期内只要核心标的收盘未破5日线且未跌停（-10%/-20%），Y状态延续，每日递推Y+n。缓冲期结束后，若核心标的仍维持5日线之上且未跌停，Y模式继续延续；若任一条件不满足（破5日线或跌停），则立即退出Y，回归H。【新增】**P-方向豁免触发的Y模式同样适用3日缓冲窗口，起算日为豁免确认当日（即P-方向确认日或T+1日，以实际触发豁免的日期为准）。** **Y模式单次最长持有周期为5个交易日**，若5日内未创出新高（收盘价高于进入Y模式后最高收盘价），则无论盈亏强制清仓，退回H。
- 混沌期与妖股模式的锚点设置：
1. 混沌期起始锚点（H0）：E确认日的次日记为H0，状态标记为`H（混沌期，H+0）`。每日递推H+n，用于跟踪混沌期时长。H0不是主线锚点，不参与Ca→G2判定。
2. 妖股模式起始锚点（Y0）：Y模式触发日（单日满足条件即生效）的首日记为Y0，状态标记为`Y（妖股模式，Y+0）`，并记录核心妖股代码及风格类型（连板型/趋势型）。每日递推Y+n。【新增】**P-方向豁免触发Y时，Y0记为豁免确认当日，核心妖股代码为豁免标的。** Y模式终止条件：①核心标的收盘破5日线；②核心标的出现跌停（-10%/-20%）；③Y模式持续超过5个交易日未创新高；④市场出现新主线（任一板块主线评分≥4.0且中军站上5日线）。满足任一即退出Y，回归H或切换至新主线。


## 二、环境等级与仓位上限

| 等级 | 量化标准 | 总仓位 |
|------|---------|--------|
| **S级** | 沪指>20日线 + 成交>2万亿 + 连板高度>5（缺一不可） | 仓4(40%) |
| **A级** | 沪指站上5日线 + 成交1.5-2万亿 | 仓3(30%) |
| **B级** | 沪指与5/20日线粘合，成交1-1.5万亿 | 仓2(20%) |
| **C级** | 沪指<20日线（核心），或成交<1万亿 | 仓1(10%) |

> **C级环境重要注释**：C级环境下，无论成交额多大，总仓位上限均为仓1。放量滞跌/弱势反弹不因成交额大而放松仓位纪律。

盘中动态升级：半日成交≥前日全日×0.8且沪指涨>1.5%；或上涨>4000家且涨停>80家，则当日自动上调一级。

> **盘中动态升级注释**：盘中动态升级仅适用于环境等级从C→B或B→A，**不改变C级核心定义（沪指<20日线）** 。即使触发动态升级条件，若沪指仍<20日线，总仓位上限仍为仓1。


## 三、主线强度评分（AI内部计算不需要展示步骤）

评分卡：

| 指标/权重 | 5分 | 3分 | 1分 |
|----------|-----|-----|-----|
| 政策强度(20%) | 国家级重磅 | 地方政策 | 无 |
| 资金流入(30%) | 板块涨幅>5% | >2% | <2% |
| 涨停数量(20%) | ≥15家 | ≥10家 | <5家 |
| 先锋封单(15%) | >5亿 | >2亿 | ≤2亿 |
| 中军表现(15%) | 核心中军涨停 | 核心中军涨>5% | 核心中军平或跌 |

阈值：≥4.5核心主线；4.0-4.4次级主线；3.0-3.9轮动方向；<3.0放弃, （注：该阈值可基于环境等级或市场风格相对下调，下调幅度及使用标准必须在复盘第3项中明确标注。）。

**执行流程（必须逐条，不可跳过）** ：
1. 涨停数量：筛选板块涨停，炸板不算。
2. 先锋封单：取板块内最大封单额。
3. 资金流入：板块涨幅，辅以主力净流入微调（>10亿上调一档，<-10亿下调一档）。
4. 中军表现：取核心中军涨幅。
5. 政策强度：从产业催化判断。


## 四、锚点与候选池管理

- **锚点T**：
 1.锚点T对应主线退潮确认后预置锚点t晋级成正式锚点T。
 2.如果没有预置锚点，候选池方向通过三日缓冲(即三个交易日评分高于主线)取代。
 3.**锚点只可被取代不可取消，即使主线确认退潮**,如果没有主线则对应H和Y状态下的起点作为锚点取代（见状态机转移规则）。
 4.旧锚点T在E确认后不再作为交易参考，但保留其标记用于历史全景表。当前市场的"有效锚点"切换为H0或Y0，直到出现新主线Ca。
- **预置锚点t**：退潮窗口期（E后2交易日）内第一个Ca日方向，立即设为预置锚点，不可更改。
- **指数共振确认**：预置锚点t的Ca日必须与**指数企稳点**（沪指在连续下跌后首次收阳或长下影线，且上涨家数从冰点回升）同时发生，否则该方向仅作为普通候选，不设为预置锚点。若指数未企稳而板块独立走强，则按Y模式或轮动处理。校验规则：每日复盘时，若全景表中记录有"预置锚点t"或"锚点T"，其对应的指数企稳日必须在全景表的"企稳信号"列有明确标注。若无标注，则判定为锚点设置不合规，需重新校验当日的指数形态数据。
- **候选池**：窗口期内Ca→窗口期候选（优先）；窗口期外Ca→普通候选；连续2日评分<3.0且中军破20日线淘汰。
- **候选加速晋级**：非窗口期下，候选方向完成C→D1→G2-1且G2-1评分≥4.0、核心中军涨幅≥3%，即可直接进入双锚点并行期（旧主线仓2，新方向仓2）。
- **双锚点并行期仓位管理**：当市场同时存在旧主线（G/D阶段）和新候选方向（G2-1确认），且满足候选加速晋级条件时，可进入双锚点并行期，最长持续5个交易日。**总仓位上限 = min(环境等级上限, 旧主线分配仓位 + 新方向分配仓位)** 。其中旧主线分配仓位不超过环境等级上限的一半（向上取整），新方向分配仓位不超过环境等级上限的一半。示例：环境等级A级（上限仓3），旧主线仓2，新方向仓2 → 总仓位取3。需减仓1，优先减仓评分较低、或中军趋势走弱的一方。若并行期结束（5日到期或一方确认退潮），恢复单主线仓位规则。
- **全景表状态节奏**：以主线启动点为锚点T，主线节奏为市场状态。其他方向维持自己的节奏状态。


## 五、三大核心角色买卖锚定

> 各角色的识别标准（量比、封单、连板数等）详见第十二章12.3节及新增12.5节。本章仅规定买卖锚定逻辑与止损规则。

| 角色 | 核心锚定 | 止损规则 |
|------|----------|----------|
| **核心中军** | 均线系统 | 破10日线减半，破20日线清仓 |
| **趋势先锋** | 新高（均线辅助） | 三日不新高或破5日线，减半或清仓 |
| **连板先锋** | 量能 + 断板 | 断板即走，不参与首阴、不反包 |

注：活口、卡位为临时观察角色（见12.3节），不设独立止损规则。


## 六、核心买点

**"活口"定义**：

- 分歧日（D1/D2）中，属于主线方向、跌幅<3%、分时在均线上方、且未破5日线的标的。
- 活口代表"板块分歧中的幸存者"，是弱转强修复时最可能成为新龙头的标的。

**操作触发条件**：
- D1日确认活口 → 次日（D1-3→G2-1）竞价高开3-7%+放量>30%+15分钟拉升 → 执行D2活口弱转强买点（仓2-3）。
- 若活口次日直接走弱（低开>3%无承接），则放弃，等待下一个活口。

| 买点 | 触发条件 | 仓位 | 时间窗口/止损 |
|------|---------|------|-------------|
| C-A启动 | Ca日，≥2一字+≥1换手+板块>2%（趋势型可弹性：中军>3%+涨停≥3家） | 仓3-4 | 当天参与，隔日不强则减 |
| C-B确认 | Cb日，龙头封单较Ca增>50%+新增≥2首板 | 仓2 | 当天参与 |
| D1开板回封 | D1日，龙头开板后午盘前回封，封单/成交>1.5 | 仓4 | 当天打板，不回封放弃 |
| D2活口（优先先锋）弱转强 | D1-3→G2-1，竞价高开3-7%+放量>30%+15分钟拉升 | 仓2-3 | 次日早盘确认 |
| D3中军低吸 | D1-2/D2-2，中军回踩5/10日线缩量企稳，次日不创新低 | 仓2-3 | 尾盘或次日低吸 |
| G加速持有 | G2阶段，评分≥4.5 | 持仓不动 | 不加仓 |
| B冰点套利 | E后或者H混沌期，连跌≥2天+前主线核心缩量企稳（连续2日跌幅<3%且成交缩量≥40%） | 仓1-2 | 隔日套利 |


## 七、卖出与止损量化

### 7.0止损原则

| 层次 | 触发条件 | 执行 |
|------|---------|------|
| 主动止损 | 低开>3%无承接；冲高回落次日低开 | 开盘15分钟内 |
| 标准止损 | 破5日线减半；破20日线或断板清仓 | 收盘前 |
| 强制清仓 | 跌停；板块批量跌停≥3只；指数跌>3% | 盘中立即 |
| 退潮预警 | 中军连续2日破5；评分连续2日<4.0；先锋断板无回封 | 减仓 |
| 退潮确认E | 中军破20日线+批量跌停≥3只+评分<3.5 | 清仓 |

### 7.1止损规则差异

| 风格 | 先锋止损 | 中军止损 |
|------|----------|----------|
| **趋势主导** | 三日不新高或跌破5日线 | 跌破10日线减半，20日线清仓 |
| **连板主导** | 断板即走 | 跌破5日线减半 |

### 7.2 辅助离场信号（非强制）

| 信号 | 操作 | 说明 |
|------|------|------|
| 乖离率＞10%+滞涨 | 可减仓1/3 | 主动止盈 |
| 乖离率＞15%+滞涨 | 可再减1/3 | 主动止盈 |

## 十二、复盘报告生成补充协议

### 12.0 初始状态获取

1. 从 `【历史策略快照】` 提取昨日全景表**最后一行**的"状态"、"主线锚点及阶段"、"候选池及阶段"作为今日初始状态（AI内部处理不要展示）。
2. 若今日数据满足状态转移条件，更新状态；否则状态不变，天数(n)按交易日历递推增加1。
3. 若状态不变则**强制提取**主线锚点当前所处的阶段标记(如G2-3中的数字3)，作为今日n值计算的起点。

### 12.1 环境等级判定

1. 读取`【大盘指数数据】`的上证收盘点位、20日均线、成交额(沪+深)。
2. 读取`【涨停个股数据】`中的最高连板高度。
3. 按三项标准（指数>20日线，成交额>2万亿，连板高度>5）判定S/A/B/C。

### 12.2 主线评分流程

1. 从`【板块行情数据】`读取对应板块的涨幅、涨跌比、主力净流入。
2. 从`【涨停个股数据】`筛选该方向涨停股，统计数量。**归属以'板块'字段为准**，一只股票最多归入一个方向。
3. 从`【核心中军行情数据】中筛选该方向的核心中军。核心中军的定义为：该方向中成交额最大且市值居前（若冲突，成交额优先）。取该核心中军的当日涨幅作为评分依据。若该方向无明确单一大市值中军（如板块分散），则取成交额前三名的算术平均涨幅。
4. 从`【产业催化电报】` 获取政策/产业消息计算政策强度评分。
5. 按五项权重计算得分。**评分过程不出现于正文。**

### 12.3 角色输出规范（常规日）

1. 主线方向，尽量输出以下所有角色清单。清单末尾注明"**当前最优标的：[标的名称]，理由：[基于风格优先级和数据 的简短理由]**"。
2. **只做主线，不做支线轮动**，支线角色只观察不买入必须标明。

| 角色 | 识别标准 |
|------|---------|
| **连板先锋** | 属该方向，**连板数最高且至少大于等于2**，封板时间早，封单强。只能10cm主板。*注：在Ca日（指数共振日），连板先锋的识别应遵循12.5.1的锚定规则（时间窗口放宽至前1日）。非Ca日则按常规标准（仅当日）识别。* |
| **趋势先锋** | 属该方向，量比≥1.5，趋势评分最高，≤2板。优先100元以内10cm主板。*注：在Ca日（指数共振日），趋势先锋的识别应遵循12.5.2的锚定规则。* |
| **核心中军** | 属该方向，核心中军的定义见12.2节3条。*注：在Ca日（指数共振日），核心中军的识别应遵循12.5.3的锚定规则。* |
| **活口** | 属该方向，分歧日跌幅<3%，分时在均线上方。 |
| **卡位** | 龙头断板当日逆势涨停。 |

主线风格判断：计算（连板先锋数量 + 3×涨停股中连板占比）与（核心中军涨幅% + 5×核心中军成交额占板块比例），若前者大于后者则为连板主导，否则为趋势主导。
- **趋势主导风格**下，优先趋势先锋 > 核心中军 > 连板先锋。
- **连板主导风格**下，优先连板先锋 > 核心中军 > 趋势先锋。

### 12.4 操作建议生成

1. 从全景表确定当前**状态标记**。
2. 从**状态速查表**检索对应**操作指令**。
3. 将操作指令与角色清单中的最有代表的标的填入全景表。
4. 将操作指令、买卖点规则与角色清单中的最优标的结合，填入明日计划（复盘报告）或者执行清单（盘前策略）。

### 12.5 Ca日角色锚定规则（指数共振日的标准化识别）

在指数企稳点（连续下跌后首次止跌或长下影线）出现共振的Ca日（首次批量涨停），应在此固定窗口内完成主线角色的初始锚定。该锚定结果贯穿后续整个主升周期，除非角色被更强者取代。

#### 12.5.1 连板先锋锚定

- **时间窗口**：Ca日及**前1个交易日**。
- **识别标准**：取该时间窗口内，属于该方向且**连板数最高（至少≥2板）** 的10cm主板标的。若最高连板数=1（即只有首板），则**当日无连板先锋**，以趋势先锋为主。
- **原因**：避免漏掉提前1日启动的龙头（如电力5月18日启动，5月19日指数共振日已4板），同时防止将普通首板误认为连板先锋。

#### 12.5.2 趋势先锋锚定

- **时间窗口**：Ca日当天。
- **识别标准**：取**量比≥1.5** 且 **涨幅≥7%（10cm主板）或≥10%（20cm）** 的标的，按量比从高到低排序取第一。若无满足标的，则取当日**成交额最大的涨停板**（作为趋势中军替代先锋角色）。
- **原因**：量比≥1.5是主动进攻的量化门槛，涨幅要求过滤跟风杂毛。

#### 12.5.3 核心中军锚定

- **时间窗口**：Ca日当天。
- **识别标准**：取**成交额最大**且**市值居前（板块内前3）** 的标的。若该标的同时满足趋势先锋锚定条件，则优先标记为趋势先锋，核心中军另选成交额第二大的标的。
- **原因**：完全遵循规则手册原定义（12.2节3条），不添加主观条件。

#### 12.5.4 后续确认与调整

- 锚定后的角色在后续G/D循环中可能被新的先锋超越（如新连板龙头出现），此时应**动态替换**：新连板先锋的连板数必须大于旧先锋，且封单更强。
- 趋势先锋若被卡位（量比更高、趋势评分更高），则替换。
- 核心中军一般不变（除非出现明显的成交额碾压）。

### 12.6 全景表输出格式

1. 所有复盘报告必须包含此表，且作为下一日输入载体。
2. 全景表必须从T（锚点日）开始，中途可以跳过。
3. 状态栏是状态机中的一种状态标记，状态唯一并且与锚点、主线状态一致，状态转变必须符合状态机变化的客观规律和转移规则。

### 12.7 节奏模型

> 节奏模型是主线的"生理年龄估算"，用于辅助判断当前主升周期可能处于哪个阶段（启动/分歧/确立/衰竭/退潮）。但它只是一个参考框架，**不取代状态机的判定**。当节奏模型与状态机输出的状态不一致时，**绝对服从状态机**——状态机是法律，节奏模型是经验。

| 环境 | 周期长度 | 节奏数组 | 数组节点含义 |
| :--- | :--- | :--- | :--- |
| **S级** | 13日周期 | [**0**, 2, 4, 9, 11] | **0=启动**，2=分歧，4=确立，9=衰竭，11=退潮 |
| **A/B级** | 9日周期 | [**0**, 2, 4, 6, 8] | **0=启动**，2=分歧，4=确立，6=衰竭，8=退潮 |
| **C级** | 无固定节奏 | null | 仅适用妖股模式 |

```
启动分歧四确立，衰竭退潮随后来。
S级后段拉长看，C级妖股独自嗨。
```
